<p>An updated version of the FCoE TechBook (v10.0) has been posted to powerlink and <a href="http://www.emc.com/collateral/hardware/technical-documentation/h6290-fibre-channel-over-ethernet-techbook.pdf" target="_self">emc.com</a>.</p>
<p>New in this version is a chapter titled “EMC Storage in an FCoE Environment” that was written by Shreedhan Nikam.&#0160; It contains information for VMAX&#0160;as well as&#0160;VNX and is a very welcome (and necessary) addition to an FCoE TechBook written by a storage company..</p>
<p>Also new in this version is a section for Brocade DCX that was written by Erik Paine.&#0160; It contains all of the information you&#39;ll need to know when installing an FCoE blade into a DCX.</p>
<p>Finally, I updated the Nexus 2232PP case studies to show that it is no longer necessary to bind the VFCs to the ENODE MAC of the CNA when creating VFCs for&#0160;CNAs that are attached to the 2232.&#0160; This was a change that had somehow escaped my notice and I’m very grateful to Eng Khong Toh for taking the time to call this oversight to my attention!!</p>
<p>Thanks for reading!</p>
