<p><strong><span style="text-decoration: underline;">FCoE TechBook</span></strong></p>
<p><strong></strong></p>
<p><strong>vPC overview and case studies</strong> (Courtesy of Erik Paine) – If you want to see exactly how vPC fits into an FCoE environment, check out Erik’s new section on vPC.&#0160; He provides an overview of vPC, a detailed description of the 5 basic vPC topologies (including information on which topologies support FCoE) and step-by-step instructions on how to configure the reference topology we provide.&#0160;&#0160;</p>
<p><strong>EMC Celerra Multi-Path File System in an FCoE environment </strong>(Courtesy of Keith Fu) – Keith put together a very nice overview of how MPFS can be used in an FCoE environment and provided some actual testing results that show MPFS blowing the doors off of NFS.&#0160;&#0160;&#0160;</p>
<p><strong>EMC RecoverPoint with Fibre Channel over Ethernet</strong> (Courtesy of Mugdha Kulkarni) – Mugdha did some nice work with this RecoverPoint overview. If you want to understand how to use FCoE with RecoverPoint, look no further.</p>
<p><strong>VE_Ports</strong> (Courtesy of Erik Smith) – I provided an update to the FCoE intro section that describes what a VE_Port is, how it is created and the environments it can be used in.&#0160;</p>
