<p>In my first Connectivity Changes post, I committed to providing monthly updates.&#0160; Looking back, I should have included a “no changes clause”.&#0160; Something to the effect of, &quot;if there are no connectivity changes for the month, I won&#39;t be providing an update&quot;.&#0160;</p>
<p>Having neglected to&#0160;include the aforementioned “no changes clause”&#0160;in my original post, I now feel compelled to explicitly state there were no updates published for the month of November.&#0160;</p>
<p>In the future, if no connectivity changes are published for the current month, I won&#39;t be providing an update!</p>
