<p>The updates for the month of January are listed below:</p>
<p><strong><span style="text-decoration: underline;">Brocade</span></strong> (Courtesy of Aditya Nadkarni)</p>
<p><strong>Firmware added to the January ESM</strong></p>
<ul>
<li>EOS 9.09.09</li>
<li>FOS v6.3.2b</li>
<li>FOS v6.4.1</li>
<li>FOS v6.3.2a (tagged as the target release for FOS)</li>
</ul>
<p><strong>Note: Target Releases are a new concept for the January ESM and according to the ESM footnote: <em>“are denoted by a &quot;(T)&quot; immediately following the firmware revision. Target Releases designate the latest firmware releases that EMC recommends be deployed. Target Releases are considered stable based on criteria such as minimum number of installs and runtime in the field, minimal number of reported defects, and zero instances of data loss or data unavailability. Whenever possible, please upgrade to a Target Release.”</em></strong></p>
<p><strong><span style="text-decoration: underline;">Cisco MDS</span></strong> (Courtesy of Aditya Nadkarni)</p>
<p><strong>FC-SW interoperability configuration added to the January ESM</strong></p>
<ul>
<li>Cisco NX-OS 5.0(1a) interop support with Brocade blade server modules.</li>
</ul>
<p><strong>Firmware removed from the January ESM</strong></p>
<ul>
<li>SAN-OS 3.2(3a)&#0160;&#0160; </li>
</ul>
<p><strong><span style="text-decoration: underline;">Cisco Nexus</span></strong> (Courtesy of Erik Smith)</p>
<p><strong>Firmware added to the January ESM:</strong></p>
<ul>
<li>NX-OS 5.0(2)N1(1) added for Nexus 5000 platforms</li>
</ul>
<p><strong>Hardware added to the January ESM:</strong></p>
<ul>
<li>Nexus 5548</li>
</ul>
