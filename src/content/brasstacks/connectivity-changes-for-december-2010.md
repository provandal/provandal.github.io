<p><strong><span style="text-decoration: underline;">HP Blade Server</span></strong> (Courtesy of Aditya Nadkarni and Shreedhan Nikam)</p>
<p style="padding-left: 30px;"><strong>Hardware and firmware added to the December ESM</strong></p>
<ul>
<li>
<div style="padding-left: 30px;">HP VC Flex Fabric module (571956-B21)&#0160;- This is the VC convergence module. The internal ports are&#0160;10G FCoE for the server blade CNA connectivity and there are 4&#0160;external L2 FC ports and 4 10G native Ethernet ports. These modules cannot be directly attached to FC/FCoE storage array devices and are supported for connectivity to an FC/FCF switch&#0160;with NPIV enabled.</div>
</li>
<li>
<div style="padding-left: 30px;">HP Cisco 8Gb switch module (AW564A 8Gb 24 port) - firmware 5.0.4</div>
</li>
<li>
<div style="padding-left: 30px;">IBM Brocade Converged 10GbE Switch - firmware versions v6.3.1_cee.&#0160; This is a Converged Ethernet solution by IBM. It provides fourteen internal 10Gb CEE ports for blade server connectivity, eight external 10Gb Ethernet CEE ports for LAN connectivity and eight external 8Gb Fibre Channel ports for storage and SAN connectivity.</div>
</li>
</ul>
