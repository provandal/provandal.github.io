<p>I&#39;m still working on the fourth installment of the <a href="/brasstacks/an-introduction-to-virtual-storage-networks/" target="_self">Virtual Storage Network (VSN)</a> blog post <a href="/brasstacks/virtual-storage-networks-part-1/" target="_self">series</a>, but I wanted to share this link to a <a href="https://www.youtube.com/watch?v=OiDSw3IrlfQ" target="_self">youtube video</a> that shows a very simple (2 port) VSN demo that we&#39;ll be showing next week at EMC World. &#0160;The topology that I&#39;m using in the video is shown below.</p>

<p>The demo shows a File client in &quot;VM1 Tenant 2&quot; being connected to a FIle Share on the VNX via a VXLAN tunnel. &#0160;The VSN-CS (which will be the subject of yet another blog post) was used to create the connection between &quot;Tenant Y VSN&quot; and &quot;VLAN Y&quot;. &#0160;</p>
